# استودیو چوب و هنر اُرسی — وب‌سایت نمونه‌کار، فروش و پنل مدیریت کارگاه

وب‌سایت کامل و آماده عرضه برای یک کارگاه نجاری و دست‌سازه‌های چوبی: نمایش نمونه‌کارها، شخصی‌سازی و حکاکی آنلاین، ثبت سفارش واقعی مشتری، پیگیری وضعیت سفارش، و یک **پنل مدیریت کامل** که مدیر از طریق آن همه متن‌ها، محصولات، قیمت‌ها، خدمات و سفارش‌ها را مدیریت می‌کند.

## اجرای پروژه

```bash
npm install
npm run dev      # محیط توسعه — http://localhost:5173
npm run build    # خروجی نهایی در پوشه dist (یک فایل index.html + پوشه images)
npm run preview  # پیش‌نمایش خروجی نهایی
```

## بخش‌های سایت (مشتری)

- **هیرو تعاملی:** انتخاب زنده گونه چوب، ساعت چوبی SVG زنده، نقاط تعاملی روی محصولات و آمار اعتماد — همه از پنل قابل ویرایش.
- **ویترین نمونه‌کارها:** جستجو، فیلتر دسته‌بندی و نوع چوب، مرتب‌سازی (قیمت/سرعت ساخت)، پنجره جزئیات کامل هر اثر.
- **استودیو شخصی‌سازی:** انتخاب محصول، گونه چوب، پوشش، ابعاد (از جمله ابعاد کاملاً سفارشی)، حکاکی لیزری با پیش‌نمایش زنده روی چوب، بسته‌بندی کادویی و محاسبه آنی قیمت.
- **خدمات کارگاه:** ساخت سفارشی از روی عکس، حکاکی، هدایای سازمانی، دکور تجاری، بازسازی و مشاوره — قابل مدیریت از پنل.
- **سفارش طرح دلخواه:** فرم کامل ایده/طرح سفارشی (بودجه، ابعاد، چوب، مهلت، لینک عکس مرجع) که مستقیم به‌صورت سفارش در پنل مدیر ثبت می‌شود.
- **سبد سفارش و ثبت نهایی:** اعتبارسنجی شماره موبایل ایرانی، محاسبه هزینه ارسال و ارسال رایگان بالای سقف تعیین‌شده، صدور کد پیگیری یکتا و دکمه ارسال جزئیات در واتساپ کارگاه.
- **پیگیری سفارش:** مشتری با کد پیگیری + شماره موبایل، وضعیت لحظه‌ای سفارش را روی خط زمانی (ثبت → بررسی → بیعانه → ساخت → کنترل کیفیت → ارسال → تحویل) می‌بیند.
- **شناخت چوب‌ها، نظرات مشتریان و سوالات متداول:** همه داینامیک و قابل ویرایش از پنل.
- **تماس با کارگاه:** فرم پیام مستقیم که در صندوق پیام‌های پنل مدیریت می‌نشیند (با امکان پاسخ در واتساپ).
- **کد تخفیف:** مشتری در سبد خرید کد وارد می‌کند و تخفیف درصدی (با حداقل مبلغ قابل تنظیم) خودکار اعمال می‌شود.

## پنل مدیریت

ورود از لینک «ورود مدیریت کارگاه» در فوتر سایت یا مستقیم: `#/admin`

- **رمز پیش‌فرض:** `admin123` — بعد از اولین ورود از بخش «تنظیمات سایت ← امنیت» حتماً تغییرش دهید.
- **داشبورد:** تعداد سفارش‌های جدید، کل سفارش‌ها، درخواست‌های سفارشی، مبلغ سفارش‌های فعال، درآمد تحویل‌شده‌ها، نمودار توزیع وضعیت‌ها و آخرین سفارش‌ها.
- **سفارش‌ها:** جستجو (کد/نام/موبایل)، فیلتر وضعیت و نوع، خروجی Excel (CSV)، مشاهده کامل مشخصات مشتری و اقلام، تغییر وضعیت با ثبت در سابقه، یادداشت داخلی مدیریت، حذف سفارش، دکمه تماس و پیام واتساپ به مشتری، **چاپ فاکتور** و برای سفارش‌های طرح سفارشی **ثبت مبلغ نهایی** تا مشتری در پیگیری سفارش آن را ببیند.
- **پیام‌های تماس:** صندوق پیام‌های فرم تماس سایت با وضعیت خوانده‌شده/نشده و پاسخ سریع در واتساپ.
- **کدهای تخفیف:** ساخت کد درصدی با حداقل مبلغ سفارش و فعال/غیرفعال‌کردن آنی.
- **درخواست‌های طرح سفارشی:** همان فهرست سفارش‌ها با فیلتر خودکار روی ایده‌های سفارشی مشتریان.
- **محصولات و قیمت‌ها:** افزودن/ویرایش/حذف محصول، قیمت پایه، دسته‌بندی، ابعاد، وزن، زمان ساخت، عکس (آپلود از دستگاه با فشرده‌سازی خودکار، گالری آماده یا آدرس دلخواه)، داستان ساخت، ویژگی‌ها، چوب‌های قابل سفارش، فعال/مخفی‌کردن در سایت.
- **چوب‌ها، پوشش و ابعاد:** ویرایش نام، توضیح، ضریب قیمت هر گونه چوب، هزینه پوشش‌ها و گزینه‌های ابعاد — قیمت‌های سایت بر همین اساس لحظه‌ای محاسبه می‌شود.
- **خدمات، نظرات و سوالات متداول:** افزودن/ویرایش/حذف و فعال/مخفی‌کردن هر مورد.
- **تنظیمات سایت:** نام برند، همه متن‌های هیرو و آمار، متن‌های فوتر، اطلاعات تماس و شبکه‌های اجتماعی، شماره واتساپ مقصد سفارش‌ها، هزینه ارسال و سقف ارسال رایگان، قیمت بسته‌بندی کادویی، تغییر رمز مدیریت.
- **مدیریت داده‌ها:** دانلود پشتیبان کامل (JSON)، بازیابی از پشتیبان، حذف همه سفارش‌ها و بازنشانی کارخانه‌ای.

## مدل داده و نکته استقرار

تمام داده‌ها (محصولات، تنظیمات، سفارش‌ها، سبد مشتری) به‌صورت پایدار در `localStorage` مرورگر ذخیره می‌شود (`orsi-studio-db-v1`)؛ بنابراین بدون هیچ سروری، کل چرخه «ثبت سفارش مشتری ← مشاهده و مدیریت در پنل» واقعاً کار می‌کند و با رفرش صفحه هم چیزی پاک نمی‌شود. برای عرضه عمومی چنددستگاهی (مدیر روی سیستم جدا و مشتری‌ها روی گوشی خودشان)، کافیست همین لایه داده (`src/woodcraft-studio/store/StoreContext.tsx`) به یک API واقعی وصل شود؛ ساختار تایپ‌ها در `store/types.ts` برای همین کار طراحی شده است. خروجی JSON پشتیبان در پنل، انتقال داده‌ها بین سیستم‌ها را همین حالا هم ممکن می‌کند.

## ساختار کد

- `src/woodcraft-studio/WoodcraftStudioApp.tsx` — اپ اصلی سایت مشتری
- `src/woodcraft-studio/store/` — لایه داده: `types.ts` (تایپ‌ها)، `seed.ts` (داده اولیه)، `StoreContext.tsx` (ذخیره‌سازی و اکشن‌ها)
- `src/woodcraft-studio/components/` — بخش‌های سایت (هیرو، ویترین، شخصی‌ساز، خدمات، سفارش سفارشی، پیگیری، سبد، فوتر و…)
- `src/woodcraft-studio/admin/` — پنل مدیریت (`AdminApp`، `AdminOrders`، `AdminManage`، `AdminSettings`)
- `src/woodcraft-studio/data/products.ts` — کاتالوگ پایه چوب‌ها/محصولات و توابع فرمت قیمت و اعداد فارسی
- `public/images/` — تصاویر محصولات
